# 🚀 Guía de Inicio Rápido

## Requisitos Previos

Asegúrate de contar con lo siguiente antes de comenzar:

* **Python:** Versión **3.11 o superior**.
* **Dependencias:** Instala todos los paquetes necesarios ejecutando el siguiente comando en tu terminal:

  ```bash
  pip install -r requirements.txt
  ```

---

## 📂 Estructura y Ejecución

* **Dataset:** Los datos necesarios para el proyecto ya están incluidos dentro de la carpeta `data/`.
* **Ejecución:** Puedes explorar el desarrollo y ejecutar los modelos abriendo el notebook de Jupyter:
  * `Actividad4.ipynb`
